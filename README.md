# 🚗 Car Price Prediction using Machine Learning

## 🚀 Overview
This project predicts the selling price of cars based on features like present price, fuel type, seller type, transmission, and more.

---

## 📊 Dataset Features
- Car_Name
- Year
- Selling_Price
- Present_Price
- Kms_Driven
- Fuel_Type
- Seller_Type
- Transmission
- Owner

---

## 🧠 ML Model Used
- Linear Regression
- Random Forest Regressor (Best Model)

---

## 📈 Key Insights
- Newer cars → higher resale value
- Petrol vs Diesel shows pricing variation
- Automatic cars tend to have higher resale price
